# Raqeeb evaluation cases

These are deterministic regression cases, not machine-learning training data. Each case records a short source program and its expected static candidate count. The suite includes safe and unresolved counterexamples so a dangerous method name alone cannot pass as a finding. No case is executed as uploaded application code.

The first implemented pack is SQL injection. The other four competition packs remain scoped but not claimed complete; see `docs/FOCUSED_SCOPE.md`.
